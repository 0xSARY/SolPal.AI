Get started

Install Solpal in 60 seconds.

No account. No signup. Just install and go.

1
Clone the repo
Download from GitHub and add your free Google AI Studio key
2
Open Chrome
Go to chrome://extensions and enable Developer Mode
3
Load unpacked
Click Load unpacked and select the solpal folder
4
Visit any dApp
Click the Solpal icon and hit Analyze. That's it.
